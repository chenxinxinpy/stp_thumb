# 三维模型查看器 · GPU 渲染版

支持 STL / STP / STEP 的 GPU 三维模型查看器。

## 运行

```bash
pip install PySide6 numpy trimesh cadquery-ocp vispy
python viewer.py [模型文件]
```

也可把模型文件直接拖到窗口。

## 架构

| 文件 | 职责 |
|---|---|
| `viewer.py` | 主程序：VisPy 单窗口、交互、信息叠加 |
| `model_loader.py` | STL（trimesh）/ STEP（OCCT）读取与三角化 |
| `analysis.py` | 包围盒精确计算；壁厚射线估算 |
| `gl_widget.py` | 可复用 VisPy 渲染组件（供二次开发嵌入） |

**渲染后端**：VisPy + OpenGL（RTX 4060 实测 66 万面创建 0.02 秒，Blinn-Phong 平滑着色，MSAA 抗锯齿）。

**为什么是单窗口**：实测把 VisPy 原生 widget 嵌入 PySide6 的 QMainWindow / QSplitter 后，OpenGL 不合成（全白）。故采用 SceneCanvas 作为唯一顶级窗口。旧 VTK 方案及其 DPI workaround 已完全移除。

## 操作

| 按键 | 功能 |
|---|---|
| O | 打开文件 |
| C | 切换颜色（蓝 / 橙 / 绿 / 粉） |
| 1 / 2 / 3 / 4 | 分辨率档位（低 / 中 / 高 / 超高，见下） |
| F | 适配视图 |
| R | 重新加载 |
| E | 切换结构边线（暗面勾边，看清孔/槽/台阶） |

鼠标：左键旋转 · 右键平移 · 滚轮缩放。

## 信息面板

左上角叠加显示：文件名、格式、三角面数、分辨率档位、包围盒长宽高、壁厚估算。
左下角常驻操作提示。中文字体使用系统「黑体」。

## 分辨率档位（仅 STEP）

| 档位 | 精度定义 | 面数（500406.stp） | 耗时 |
|---|---|---|---|
| 低 | 相对 diag/200，角 0.4rad | 3.4 万 | <1 s |
| **中（默认）** | 相对 diag/500，角 0.2rad | **10.3 万** | 6 s |
| 高 | 绝对 0.1mm / 1° | 583 万 | 62 s |
| 超高 | 绝对 0.01mm / 0.5° | 约 5.8 亿 | 不可行（有面数保护会拒绝） |

**关于绝对精度**：按用户指定的 0.1mm/1° 与 0.01mm/0.5° 实现为高/超高档。
实测 0.1mm 单模型就 583 万面/62 秒，0.01mm 达数亿面，故默认用中档（相对精度，快且不失真），
需要极高精度时按 `3` 切到高档。有 300 万面安全保护，超限会明确提示并拒绝。

STL 面片由文件本身决定，不能细分。

## 暗面结构显示

- 环境光强度 0.75（默认 VisPy 0.25 太暗），保留漫反射/高光层次
- `E` 键切换深色特征边线（二面角 >25°），勾出孔、槽、台阶轮廓，暗面也看得清
- 超大网格（>300 万面）自动跳过边线提取，避免卡顿

**壁厚口径**：STEP 用 OCCT 射线测内壁-外壁间距，标注「射线估算」；STL 无实体拓扑，给「网格近似（低置信度）」。
